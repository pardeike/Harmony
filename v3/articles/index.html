Guides

Install Harmony and choose a patch type, or jump to the feature you need.

Start here

  • Introduction: how Harmony works and what your runtime needs to support.
  • Install and apply patches: add the library, register patches, and remove them.
  • Choose a patch type: find the right API for the change you want to make.
  • What's new in v3: Infix, generated bodies, and state across await and yield.

Patch methods

  • Prefix: change arguments, supply a result, or skip the original.
  • Postfix: read or change the result after completion or a skip.
  • Finalizer: run cleanup on success or failure and handle exceptions.
  • Reverse patch: call a frozen copy of an implementation from your own stub.

Infix

  • Patch an operation: apply prefixes, postfixes, and finalizers inside a method.
  • Recipes and instruction edits: insert, replace, or remove operations and manage groups of patches.
  • Limits and unusual cases: understand selection, argument scope, and state lifetime.

Transpilers

  • Rewrite instructions: edit a method's compiled instructions.
  • CodeInstruction: work with operands, labels, and exception boundaries.
  • CodeMatcher: find instruction patterns and edit them.

Coordinate your patches

  • Annotations and targets: declare target methods and organize patch classes.
  • Injected values: access arguments, results, instances, and shared state.
  • Ordering and priorities: control the order of patches from different authors.
  • Execution flow: see how Harmony combines the patches on a method.
  • Prepare, target, and clean up: control patch installation with helper methods.

Reference guides

  • Reflection and logging: find members, read private values, and write diagnostic logs.
  • Runtime edge cases: account for inlining, generics, and native methods.

For public types, signatures, and parameters, use the API reference.
